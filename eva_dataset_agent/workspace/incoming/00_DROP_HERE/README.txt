EVA AI - DATA COLLECTION DROP ZONE

1. text       : TXT, MD, JSON, JSONL
2. images     : JPG, PNG, diagrams, charts
3. documents  : PDF, DOCX
4. audio_video: Audio and video files
5. links      : Source URLs in TXT files

IMPORTANT:
- Original files should be preserved.
- Do not mix unrelated datasets intentionally.
- Keep source URL, author/publisher and license information.
- Do not upload passwords, API keys or private personal data.
- Do not put test/benchmark answers into training data.
- EVA Dataset Agent will process copied files, not modify originals.
